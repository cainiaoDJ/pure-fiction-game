# 《纯属虚构：第七码头》

完全架空的黑色幽默文字冒险游戏。它讨论“单方叙事、程序文件、截图传播和 AI 建议”如何在热点中彼此越界；不对应任何现实人物、机构或未决事件。

## 使用

解压后直接双击 `index.html`，无需安装 Node.js、服务器或网络服务。

## 文件

- `index.html`：页面骨架
- `style.css`：复古 RPG 界面与自适应布局
- `game.js`：12 个剧情章节、调查分支、可信度结算与 3 个结局；正常游玩约 15–25 分钟
- `assets/`：4 张本地场景背景图，会随剧情真正切换

可将整个 `pure-fiction` 文件夹压缩后直接分发。
